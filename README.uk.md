**ByByte Nano** — це компактна та зручна для початківців навчальна робототехнічна платформа з лінійки ByByte. Вона створена для швидкого складання, безпечного використання у навчальних аудиторіях та наочного вивчення основ робототехніки: електроніки, сенсорів, керування двигунами та вбудованого програмування. Порівняно з більш просунутою ByByte Mega, версія Nano робить акцент на простоті та доступності, зберігаючи можливість розширення.

- Суміжний проєкт: ознайомтесь з більш функціональною версією — ByByte Mega ([ByByte Mega](https://github.com/ByByte-diy/ByByteMega/blob/main/README.md)).

### Основні можливості
- Дружня до новачків: просте складання та зрозуміле розміщення елементів
- Компактна плата: оптимальні габарити для класних занять і воркшопів
- Модульність: роз’єми для підключення розширень та сенсорів
- Відкрита апаратна частина: наявні схема та файли плати
- Відкрите ПЗ: сумісність зі звичними Arduino‑інструментами

### Огляд апаратної частини
- Основна плата: ByByte Nano PCB
- Мікроконтролер: сумісний з Arduino, у форм‑факторі Nano (ATmega328)
- Типові периферії: драйвери двигунів, датчики лінії, світлодіоди, стабілізація живлення
- Роз’єми: чітко промарковані входи/виходи та живлення для швидкого прототипування

### Технічні характеристики (загальні)
- Живлення: батарея 9 В (PP3/«Крона»)
- CPU: Arduino Nano (ATmega328)
- Привід: мотори N20 з редуктором, приблизно 600–1000 об/хв
- Зв’язок: USB (Arduino Nano), Bluetooth (HC‑02/HC‑05/HC‑06), опційно Wi‑Fi через ESP32‑CAM

### Датчики та інтерфейси
- 5 датчиків лінії: рух по лінії
- Бічні оптичні аналогові датчики: навігація в лабіринті або обхід перешкод
- Передній датчик відстані: ультразвукове вимірювання дальності
- Аналоговий датчик світла: інтенсивність навколишнього освітлення
- ІЧ‑приймач: керування ІЧ‑пультом
- Bluetooth: підтримка керування зі смартфона або ПК
- 2× WS2812 RGB: «фари» та візуальний зворотний зв’язок
- Пасивний бузер: звуковий зворотний зв’язок

### Інша периферія
Є можливість встановити опційний модуль ESP32‑CAM для передачі відео через Wi‑Fi. ESP можна програмувати безпосередньо з робота; встановіть перемички J1–J3 відповідно до схеми. Також можна налаштувати обмін даними між ESP та Arduino Nano для керування роботом через Wi‑Fi.

### Мобільність
Два бічні колеса забезпечують диференціальне (танкове) керування для точного контролю руху.

### Сумісність
Повністю сумісний з Arduino IDE та широким спектром бібліотек Arduino, що робить платформу доступною як для початківців, так і для досвідчених користувачів.

### Освітній фокус
Ця платформа розроблена для допомоги школярам та студентам розвивати основні навички програмування через роботу з практичними робототехнічними проектами. Вона надає можливості:
- Вивчати інтеграцію датчиків та обробку даних.
- Програмувати алгоритми руху для уникнення перешкод, слідування по лінії та навігації в лабіринтах.
- Використовувати візуальний та аудіальний зворотний зв'язок для підвищення інтерактивності.
- Ознайомитись з основами побудови робоплатформ на базі контролерів та комунікації (керування)

### Нотатки зі збирання
- Окрім друкованої плати та готових модулів потрібні ще кілька дискретних компонентів; дизайн орієнтований на просту пайку та доступні модулі
- Перед пайкою модулів живлення встановіть правильні вихідні напруги (5 В та 3,3 В), щоб захистити чутливу електроніку
- Перед першим увімкненням перевірте полярність; бажано вмикати без вставлених модулів і перевірити всі лінії живлення
- Почніть із перевірки живлення та логіки, потім під’єднуйте двигуни й сенсори
- Тримайте дроти короткими та надійно закріпленими, щоб зменшити наведені перешкоди
- На завершення протестуйте робота тестовими скетчами перед повноцінним використанням

### Відомість елементів (BOM)

Повний перелік — **49 позицій** із позиційними номерами, кількістю, номіналами та фото компонентів — у **[BOM.md](BOM.md)**.

Коротко: плата ByByte Nano, Arduino Nano, драйвер двигунів (DRV8834), мотори N20 з колесами та кріпленнями, модуль датчиків лінії (5 каналів), ультразвуковий датчик, Bluetooth-модуль (HC-02/HC-05/HC-06), два DC-DC buck-модулі, ESP32-CAM (опційно), а також пасивні компоненти, роз’єми та механіка.

### Вирішення проблем
- Немає живлення: перевірте полярність і вихід стабілізатора
- Не прошивається по USB: перевірте вибір плати/порту, драйвери та положення джамперів J1–J3
- Двигуни не крутяться: перевірте підключення та справність драйвера
- Сенсори не відповідають: перевірте лінію 5 В та підключення
